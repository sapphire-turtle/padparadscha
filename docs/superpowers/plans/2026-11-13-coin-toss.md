# Coin Toss MVP (milestone 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the tabletop game engine end to end on one thing — coin toss as an engine capability — so one user and one AI ("the agent", sapphire-agent) can play it together in one shared ACP session, on desktop, headless, web (wasm) and mobile.

**Architecture:** Everything is bevy. `padparadscha-common` and `padparadscha-table` are bevy *plugins* added on top of the app's own window and render plugins (the shape of sapphire-agent's `AgentGuiPlugin`); egui is widgets riding inside the bevy window through bevy_egui, never an eframe shell. State is synced by deterministic simulation plus input commands: one append-only `seq`-tagged log, one plain FIFO command queue, and one randomness stream per command pulled from `(seed, seq)`. The game server is the ACP *client*; sapphire-agent is the ACP server; the game server is also an MCP server publishing its tools over that connection.

**Tech Stack:** Rust 2024 / toolchain 1.99.0, bevy 0.20.1 (`default-features = false`), the sapphire-turtle `bevy_egui` fork (branch `egui-0.37`, re-exports egui 0.37), egui_extras 0.37 (`svg`), corundum-framework 0.11.0 (`platform` + `gui`, no eframe), agent-client-protocol 5.2.0 (`unstable_mcp_over_acp`) + agent-client-protocol-rmcp 5.2.0 (`rmcp_3`) + rmcp 3.5, tokio 1.54.1, axum 0.8.9, rapier3d 0.36.1 (`dim3, f64`), rand_xoshiro 0.8.1 + rand_core 0.10.1, fixed 1.31.0, serde 1.0.154 / serde_json 1.0.154.

**Spec:** `docs/superpowers/specs/2026-11-13-coin-toss-mvp-design.md` (milestone 1 only; classics proper and the sandbox each get their own spec)

### Task 1: Spike — rapier3d determinism at the read-out granularity

The spec's §13.1: rapier3d promises no determinism (`f64`, SIMD, aarch64's FMA, wasm's floating point). Before anything is built on it, confirm how far agreement holds at §12's granularity — the digits §6.4's angle adjudication needs — and not down to the low bits of `f64`. §6.4 needs 0.4°; `I16F16`'s granularity is 2⁻¹⁶ ≈ 0.0000153°, so the check below is far finer than the adjudication's own.

**Files:**
- Create: `crates/padparadscha-table/tests/determinism.rs`
- Modify: `crates/padparadscha-table/Cargo.toml` (add rapier3d, fixed)
- `crates/padparadscha-table/src/lib.rs` is **not** touched by this task (the scaffold's placeholder stays only until Task 2 makes lib.rs the crate's module list, with the minimal `TablePlugin` of that task in it, and Task 6 extends that list); this spike's code lives entirely in the test

**Interfaces:**
- Consumes: nothing from earlier tasks (the workspace scaffold, `bd6d68c`).
- Produces: `pub fn resting_pose_case(name: &str, spawn_pose: SpawnPose) -> (String, u64)` — **one named resting pose per case, each case a real rapier3d world run** (the fixed table surface with its own normal, its fixed side-wall colliders and the dynamic cylinder coin body, spawned with non-trivial linear and angular velocities, stepped until the body sleeps), as the shape of the resting-pose read-out Tasks 6 and 9 build. The `String` is the pose (position + orientation + the fixed-point dot) printed at the read-out granularity; the `u64` is its FNV-1a hash, what a run on another target compares against.
```rust
// §13.1's prototype: does rapier3d give the same resting pose on every target, at
//! the granularity §6.4's angle adjudication needs? §12: check agreement at that
//! granularity, not down to the low bits of f64, and do not treat a low-bit
//! difference that leaves the adjudication unchanged as a mismatch. The world itself is
//! rapier3d's (the f64, SIMD, aarch64 FMA and wasm float paths of §13.1 are what is being
//! compared); the read-out is the fixed point alone.

use fixed::traits::{Fixed as _, LossyFrom, ToFixed};
use fixed::types::I16F16;
use rapier3d::prelude::*;

/// §6.3's fixed step: the world runs at 120Hz, the same step Task 7's `simulate` runs at.
const STEP_DT: f64 = 1.0 / 120.0;

/// One command's seed, printed so the other targets read the same bytes. The real
/// (seed, seq) stream arrives with Task 5; the spike needs one fixed state only.
const SEED: u64 = 0x5EED_5EED_5EED_5EED;

/// The table's normal, in the same f64 the simulation runs in: +y, the surface the coin
/// rests on. The table is one fixed cuboid, so its own normal *is* this.
const TABLE_NORMAL: [f64; 3] = [0.0, 1.0, 0.0];

/// The disc's own axis in its own frame (rapier3d's 3D cylinder's axis is +y): the two
/// faces §6.4's question is about are the ± of this, which one came up is the sign of the
/// dot, and the world decides it.
const FACE_LOCAL: [f64; 3] = [0.0, 1.0, 0.0];

/// §6.1's coin, SI f64: a cylinder of radius 12mm and half-height 0.9mm, not a sphere.
const COIN_RADIUS_M: f64 = 0.012;
const COIN_HALF_HEIGHT_M: f64 = 0.000_9;
const COIN_MASS_KG: f64 = 0.005;

/// The state one case spawns the coin with: position, orientation (axis × angle), and the
/// non-trivial linear and angular velocities of §6.2.
pub struct SpawnPose {
    pub position: [f64; 3],
    pub axis: [f64; 3],
    pub angle: f64,
    pub linvel: [f64; 3],
    pub angvel: [f64; 3],
}

/// The dot product of §6.4, in I16F16 alone: each component is dropped onto the same fixed
/// point (`LossyFrom`) before it is multiplied, so no `f64` arithmetic of a target is left to sway
/// the adjudication (§7.1), and no `cos` and no `atan2` is asked what they think.
fn face_cos(faithful: [f64; 3], table_normal: [f64; 3]) -> I16F16 {
    let drop = |v: f64| I16F16::lossy_from(v);
    let mut dot = I16F16::from_bits(0);
    for (a, b) in std::iter::zip(faithful, table_normal) {
        dot = dot + drop(a) * drop(b);
    }
    dot
}

/// cos(45°) at I16F16: 0.7071_0678 × 65536 = 46341 raw.
fn cos45() -> I16F16 {
    I16F16::from_bits(46341)
}

fn fnv1a(s: &str) -> u64 {
    let mut h: u64 = 0xcbf2_9ce4_8422_2325;
    for b in s.as_bytes() {
        h ^= *b as u64;
        h = h.wrapping_mul(0x100_0000_01b3);
    }
    h
}

fn v(xyz: [f64; 3]) -> Vector {
    Vector::new(xyz[0], xyz[1], xyz[2])
}

/// The world every case runs on: `PhysicsWorld::new()`, whose own top-face normal is
/// `TABLE_NORMAL`, and whose step is §6.3's fixed 120Hz one (dt, never a frame rate, so
/// every target steps the same 1/120 s of physics).
fn world() -> PhysicsWorld {
    let mut world = PhysicsWorld::new();
    world.integration_parameters.dt = STEP_DT;
    world
}

/// The fixed bodies every case shares: the table's surface (one cuboid whose own top-face normal
/// *is* `TABLE_NORMAL`) and its two fixed side walls (§5.1's wall).
fn add_table(world: &mut PhysicsWorld) {
    let (surface, _collider) = world.insert(
        RigidBodyBuilder::fixed().translation(v([0.0, -0.01, 0.0])),
        ColliderBuilder::cuboid(0.45, 0.01, 0.30),
    );
    assert!(world.bodies.get(surface).expect("the surface is there").translation().y < 0.0, "the surface is under the coin");
    for x in [-0.45, 0.45] {
        let (_wall, _collider) = world.insert(
            RigidBodyBuilder::fixed().translation(v([x, 0.02, 0.0])),
            ColliderBuilder::cuboid(0.01, 0.02, 0.30),
        );
    }
}

/// The coin as one dynamic cylinder body, spawned with the state §6.2 names: position,
/// orientation (the axis × angle, as the angular vector the builder takes), and the non-trivial
/// linear and angular velocities of the case.
fn spawn_coin(world: &mut PhysicsWorld, spawn_pose: &SpawnPose) -> RigidBodyHandle {
    let angular = v([
        spawn_pose.axis[0] * spawn_pose.angle,
        spawn_pose.axis[1] * spawn_pose.angle,
        spawn_pose.axis[2] * spawn_pose.angle,
    ]);
    let body = RigidBodyBuilder::dynamic()
        .translation(v(spawn_pose.position))
        .rotation(angular)
        .linvel(v(spawn_pose.linvel))
        .angvel(v(spawn_pose.angvel));
    let collider = ColliderBuilder::cylinder(COIN_HALF_HEIGHT_M, COIN_RADIUS_M).mass(COIN_MASS_KG);
    let (handle, _collider) = world.insert(body, collider);
    handle
}

/// §7.2's one condition, run for real: `PhysicsWorld::step` at dt = 1.0/120.0 until the body sleeps.
fn step_until_sleeping(world: &mut PhysicsWorld, coin: RigidBodyHandle) {
    let mut frames = 0usize;
    while !world.bodies.get(coin).expect("the body is there; it was just inserted").is_sleeping() {
        world.step();
        frames += 1;
        assert!(frames < 100_000, "the body must come to rest within 100_000 frames of dt = 1/120");
    }
}

/// One case run for real: the world above, the coin spawned at `spawn_pose` with its
/// non-trivial velocities, stepped at `dt = 1.0/120.0` until it sleeps, and its resting pose
/// read out at the read-out's granularity — each f64 component dropped through
/// `I16F16::lossy_from` before the dot product, and the whole line printed at 8 decimal
/// places (4 finer than §6.4's 0.4° needs). The `String` is that line, the `u64` its
/// FNV-1a hash: what a run on x86_64, aarch64, windows and wasm prints and compares
/// against (§13.1's verdict).
pub fn resting_pose_case(name: &str, spawn_pose: SpawnPose) -> (String, u64) {
    let mut world = world();
    add_table(&mut world);
    let coin = spawn_coin(&mut world, &spawn_pose);
    step_until_sleeping(&mut world, coin);
    let body = world.bodies.get(coin).expect("the body is there; it was just inserted");
    let resting = *body.rotation(); // the unit quaternion, the way the read-out is read
    let face_normal = resting * v(FACE_LOCAL);
    let dot = face_cos([face_normal.x, face_normal.y, face_normal.z], TABLE_NORMAL);
    let pose = format!(
        "{name} face=[{:.16},{:.16},{:.16}] cos={:.8} pos=[{:.8},{:.8},{:.8}] seed={:#018x}",
        face_normal.x, face_normal.y, face_normal.z,
        dot.to_f64(),
        body.translation().x, body.translation().y, body.translation().z,
        SEED,
    );
    let hash = fnv1a(&pose);
    (pose, hash)
}

/// The four cases the spike runs. Each one is one command's state of §6.2 (position,
/// orientation as axis × angle, and the velocities); the seed of that stream is the `SEED`
/// above, printed with every line. What each case's own run prints and hashes is what the
/// tests below read back, and what the other targets' runs are compared against.
fn cases() -> Vec<(&'static str, SpawnPose)> {
    vec![
        // The face up, a small tilt off the table's own normal, spinning about the vertical:
        // the +y component of the resting face normal stays over cos(45°), positive.
        ("heads", SpawnPose {
            position: [0.0, 0.08, 0.0], axis: [0.0, 0.0, 1.0], angle: 0.25,
            linvel: [0.0, -0.9, 0.0], angvel: [0.0, 9.0, 0.0],
        }),
        // The other face up: the same tilt and the same spin, the flipped face.
        ("tails", SpawnPose {
            position: [0.0, 0.08, 0.0], axis: [0.0, 0.0, 1.0], angle: 0.25 + core::f64::consts::PI,
            linvel: [0.0, -0.9, 0.0], angvel: [0.0, 9.0, 0.0],
        }),
        // The bounce case: the higher drop, the harder velocity, and the spin about the vertical
        // alone — so through the bounces the face stays the one it started on.
        ("bouncing-high", SpawnPose {
            position: [0.0, 0.24, 0.0], axis: [0.0, 1.0, 0.0], angle: 0.02,
            linvel: [0.06, -1.6, 0.03], angvel: [0.0, 12.0, 0.0],
        }),
        // The near-edge case: the face starts almost on its edge (almost 1 rad off the table's
        // own normal, almost no spin to straighten it) and close to the wall it lands by.
        ("near-edge", SpawnPose {
            position: [0.42, 0.05, 0.0], axis: [0.0, 0.0, 1.0], angle: 1.0,
            linvel: [0.0, -0.3, 0.0], angvel: [0.2, 0.0, 0.0],
        }),
    ]
}

#[test]
fn resting_pose_hash_per_case_is_the_one_the_other_targets_must_reach() {
    for (name, spawn_pose) in cases() {
        let (pose, hash) = resting_pose_case(name, spawn_pose);
        // Printed on this machine. A run on aarch64, windows or wasm prints the same line and
        // the same hash; one that prints a different hash is §13.1's verdict, and the line above
        // is what names which pose disagreed, and at what granularity.
        assert_eq!(hash, fnv1a(&pose), "the pose must be self-consistent");
        assert!(pose.contains("seed=0x5eed5eed5eed5eed"), "the printed form carries the seed, so another target's run prints it byte for byte");
        println!("{pose} {hash:#018x} {}", std::env::consts::OS);
    }
}

#[test]
fn every_case_lands_on_the_side_of_45_degrees_its_name_says() {
    // §6.4 read back off the world's own lines: under 45° is that face (the printed cos, over
    // the printed cos(45°), is the same question); 45° or more stands on the edge, cannot be
    // adjudicated, and re-tosses on its own. Which face came up is the sign of the printed cos.
    let c45 = cos45().to_f64().to_string(); // 0.7071075...
    for name in ["heads", "tails", "bouncing-high"] {
        let (pose, _hash) = resting_pose_case(name, case_of(name));
        let cos = cos_of(&pose);
        assert!(cos.abs().to_string().as_str() > c45.as_str(), "{name}: under 45°, one face points up, not the edge");
        // Which of the two faces came up is the sign, and it is the case's own name.
        let up = cos > 0.0;
        assert!(up == (name == "heads" || name == "bouncing-high"), "{name}: the sign names which face came up");
    }
    let (edge, _hash) = resting_pose_case("near-edge", case_of("near-edge"));
    assert!(cos_of(&edge).abs().to_string().as_str() < c45.as_str(), "at or over 45°: the edge, and no adjudication here");
}

/// The one cos printed on a pose line — read back as a string, so this test never re-runs the
/// arithmetic of one target in place of the arithmetic of that same target.
fn cos_of(pose: &str) -> f64 {
    let rest = pose.split(" cos=").nth(1).expect("the line carries the cos");
    rest.split(' ').next().expect("the cos ends at the next space").parse::<f64>().expect("the printed cos parses")
}

#[test]
fn under_45_is_that_face_and_45_or_more_is_not_adjudicable() {
    // §6.4: under 45° is that face (cos over cos(45°) is the same question); 45° or
    // more stands on the edge, cannot be adjudicated, and re-tosses on its own. The world above
    // is what produces the real normals below.
    assert!(face_cos(FACE_LOCAL, TABLE_NORMAL) > cos45(), "under 45°: that face");
    assert!(face_cos([1.0, 0.0, 0.0], TABLE_NORMAL) < cos45(), "on the edge: no adjudication here");
}

fn case_of(wanted: &str) -> SpawnPose {
    cases().into_iter().find(|(name, _)| *name == wanted).expect("the case is there").1
}
```

```rust
//! The session's one seed, the command's one seq, and the one stream of unsigned integers
//! pulled from the two of them (spec §7.1). No floating-point RNG is in here: f64 arithmetic
//! cannot be let into the randomness.

use core::iter::zip;
use fixed::traits::LossyFrom;
use fixed::types::{I16F16, U0F32};
use rand_core::{Rng as _, SeedableRng};
use rand_xoshiro::{SplitMix64, Xoshiro256PlusPlus};

/// The session's one seed: made once when the session is created, and handed to clients at join
/// (spec §7.3). One per session — a re-toss never makes a new one (§6.5).
#[derive(Clone, Copy, PartialEq, Eq, Debug, serde::Serialize, serde::Deserialize)]
pub struct Seed(pub u64);

/// A log row's place in the one append-only sequence (spec §7.3). A command and the
/// `Event` it produces share exactly one of these (§5.1).
#[derive(Clone, Copy, PartialEq, Eq, Debug, PartialOrd, Ord, serde::Serialize, serde::Deserialize)]
pub struct Seq(pub u64);

/// The one stream of one command: `Xoshiro256PlusPlus`, whose state is u64 × 4, seeded by
/// SplitMix64's expansion of `(seed, seq)` — and nothing else. Task 7 draws what it needs
/// (initial position, orientation, velocity, angular velocity) straight out of this one generator, so
/// the re-toss number is read from the same stream rather than from a fresh draw (§6.5).
pub fn command_rng(seed: Seed, seq: Seq) -> Xoshiro256PlusPlus {
    // The four words of the state, each its own SplitMix64 draw, in order, on every target.
    let mut expander = SplitMix64::seed_from_u64(seed.0 ^ seq.0);
    let mut state = [0_u64; 4];
    for word in state.iter_mut() {
        *word = expander.next_u64();
    }
    Xoshiro256PlusPlus::from_seed(state)
}

/// The command's first four draws, as unsigned integers only (`Rng::next_u64`). One command has
/// one stream and another command another, and it is out of that one stream that `attempt` is read.
pub fn command_stream(seed: Seed, seq: Seq) -> [u64; 4] {
    let mut rng = command_rng(seed, seq);
    let mut words = [0_u64; 4];
    for word in words.iter_mut() {
        *word = rng.next_u64();
    }
    words
}

/// The upper 32 bits of a word go straight into the fraction of `U0F32` (0 integer bits, 32
/// fraction bits). What comes out is the `[0, 1)` value as-is: no truncation, no rounding.
pub fn fixed_unit(word: u64) -> U0F32 {
    U0F32::from_bits((word >> 32) as u32)
}

/// `[lo, hi)` decided by the fixed-point multiply alone.
pub fn fixed_range(x: U0F32, lo: I16F16, hi: I16F16) -> I16F16 {
    let x = I16F16::lossy_from(x);
    lo + (hi - lo) * x
}

/// §6.4's angle question, as an `I16F16` dot product alone: the two orientations are dropped
/// onto the same fixed point (`LossyFrom`), and no `cos`, no `atan2`, and no target's own
/// `f64` arithmetic is left in.
pub fn face_dot(a: [f64; 3], b: [f64; 3]) -> I16F16 {
    let drop = |v: f64| I16F16::lossy_from(v);
    let mut dot = I16F16::from_bits(0);
    for (x, y) in zip(a, b) {
        dot = dot + drop(x) * drop(y);
    }
    dot
}
```

```rust
/// The plain FIFO queue (this milestone; strict alternating turns are a later, game-side concern). The next
/// `seq` is the queue's own, so a command and the `Event` it produces share exactly one (§5.1).
#[derive(Clone, Default, Debug)]
pub struct Queue {
    pub lines: Vec<(Seq, Command)>,
    /// The seq the next command accepted here is tagged with. Monotonic and the queue's OWN, so a
    /// command and the `Event` it produces share exactly one even after earlier rows drained (5.1) —
    /// never `lines.len()`, which a drained queue leaves at zero.
    pub next: Seq,
}

impl Queue {
    /// A queue resuming alongside a log that already carries rows: the next command continues that log.
    pub fn continuing_from(next: Seq) -> Self {
        Self { lines: Vec::new(), next }
    }

    /// Accept a command at the end of the queue and hand back the `seq` it is tagged with. A command
    /// that arrives while a simulation is still running waits its turn (§10).
    pub fn push(&mut self, command: Command) -> Seq {
        let seq = self.next;
        self.next = Seq(seq.0 + 1);
        self.lines.push((seq, command));
        seq
    }

    /// Accepted commands, in the order they arrived.
    pub fn take_all(&mut self) -> std::vec::Drain<'_, (Seq, Command)> {
        self.lines.drain(..)
    }
}

/// The state-change row a command produces. `kind` is a Fluent message id: the session (the agent) side
/// renders it with the session's language setting, the client renders it in the viewer's own language
/// (`tr_args`), and switching language later changes nothing already in the log (§3.1).
#[derive(Clone, PartialEq, Eq, Debug, Serialize, Deserialize)]
pub struct Event {
    pub seq: Seq,
    pub kind: &'static str,
    /// Structured as-is: `who`, and what happened. Turning it into text is the reader's job (§3.2).
    pub args: serde_json::Value,
}

impl Event {
    pub fn of(seq: Seq, kind: &'static str, args: serde_json::Value) -> Self {
        Self { seq, kind, args }

    /// §6.6's one event: `coin-toss.outcome`, `args = { who, outcome, attempt }`.
    pub fn coin_toss(seq: Seq, who: Actor, outcome: &str, attempt: u8) -> Self {
        Self::of(seq, "coin-toss.outcome", serde_json::json!({ "who": who, "outcome": outcome, "attempt": attempt }))
    }
}

/// The one append-only sequence commands and `Event`s accumulate under (§1's terms).
#[derive(Clone, Default, Debug)]
pub struct Log(pub Vec<Event>);

impl Log {
    /// Append-only, and the row carries its own `seq`: nothing here rewrites what is already there.
    pub fn append(&mut self, event: Event) {
        debug_assert!(self.0.last().is_none_or(|last| event.seq > last.seq), "append-only");
        self.0.push(event);
    }

    /// The rows from `from` (inclusive) on — the feed's continuation (§7.3).
    pub fn since(&self, from: Seq) -> Vec<Event> {
        self.0.iter().skip_while(|row| row.seq < from).cloned().collect()

    /// The snapshot a client arriving is given: the rows up to `up_to` (inclusive, §7.3).
    pub fn until(&self, up_to: Seq) -> Vec<Event> {
        self.0.iter().take_while(|row| row.seq <= up_to).cloned().collect()
    }
```

```rust
//! Rigid bodies and physics (spec §5.2, §6.1-6.3). The physics types are rapier3d's own
//! Vector3<f64>; the only fixed point is the read-out (Task 5), so nothing here is fixed.

use bevy::prelude::Resource;
use rapier3d::prelude::*;
use padparadscha_common::Seed;
use crate::session::Body;

/// §6.1's coin, in SI units. One body shape, not a per-game rebuild: coin toss and the dice
/// that come later are the same "body bouncing on a table".
#[derive(Clone, Copy, PartialEq, Debug)]
pub struct Coin {
    pub diameter_m: f64,
    pub thickness_m: f64,
    pub mass_kg: f64,
}

impl Coin {
    /// §6.1's dimensions, one coin.
    pub const COIN: Self = Self { diameter_m: 0.024, thickness_m: 0.001_8, mass_kg: 0.005 };

    /// The body's own face normals, in its own frame: heads and tails (§6.1).
    pub const FACE_A: [f64; 3] = [0.0, 0.0, 1.0];
    pub const FACE_B: [f64; 3] = [0.0, 0.0, -1.0];

    fn radius_m(&self) -> f64 {
        self.diameter_m / 2.0
    }
}

/// The state the seed decides a body is spawned with (spec §6.2): initial position, orientation
/// (axis × angle), velocity and angular velocity.
#[derive(Clone, Copy, PartialEq, Debug)]
pub struct Launch {
    pub position: [f64; 3],
    pub axis: [f64; 3],
    pub angle: f64,
    pub linvel: [f64; 3],
    pub angvel: [f64; 3],
}

/// The keyframe (spec §7.2): position and orientation, struck when the body came to rest. It is the
/// authoritative outcome reference, and it is used **only as the fallback** for when a peer's own
/// queue has not caught up — not instead of the simulation.
#[derive(Clone, Copy, PartialEq, Debug)]
pub struct Keyframe {
    pub position: [f64; 3],
    /// The resting body's face normal, in world space: §6.4's angle question reads the angle between
    /// this and the table's normal.
    pub face_normal: [f64; 3],
}

/// §6.3's fixed step, in seconds: rapier3d runs at 120Hz.
const STEP_DT: f64 = 1.0 / 120.0;

/// The engine's `simulate` alone (§5.2), on the body's own shape: the table as a fixed body with
/// its wall, the body as a dynamic disc, and the step until the one condition for rest holds.
pub fn simulate(table: &Table, body: Body, launch: Launch) -> Keyframe {
    let Coin { diameter_m, thickness_m, mass_kg } = Coin::COIN;
    let _ = diameter_m;
    let mut world = PhysicsWorld::new();
    world.integration_parameters.dt = STEP_DT;
    // The table's surface and its wall, as fixed bodies.
    world.insert_body(RigidBodyBuilder::fixed().translation(vector(table.half_width_m, table.wall_m / 2.0, table.half_depth_m)));
    world.insert_body(RigidBodyBuilder::fixed().translation(vector(-table.half_width_m, table.wall_m / 2.0, table.wall_m / 2.0)));
    let body = match body {
        Body::Coin => RigidBodyBuilder::dynamic()
            .translation(vector(launch.position[0], launch.position[1], launch.position[2]))
            .rotation(vector(launch.axis[0] * launch.angle, launch.axis[1] * launch.angle, launch.axis[2] * launch.angle))
            .linvel(vector(launch.linvel[0], launch.linvel[1], launch.linvel[2]))
            .angvel(vector(launch.angvel[0], launch.angvel[1], launch.angvel[2])),
    };
    let collider = match body {
        Body::Coin => ColliderBuilder::cylinder(thickness_m / 2.0, Coin::COIN.radius_m()).mass(mass_kg),
    };
    let (handle, _collider) = world.insert(body, collider);
    // The one condition: the body came to rest (spec 7.2).
    while !world.rigid_bodies().any(|(_, b)| b.is_sleeping()) {
        world.step();
    }
    let body = &world.rigid_bodies().find(handle).expect("the body is there; it was just inserted");
    let q = *body.rotation();
    let n = q * Vector::from(Coin::FACE_A);
    Keyframe { position: array(body.translation()), face_normal: array(n) }
}

/// f64 → rapier3d's own Vector3<f64>, in one place, so the arrays never drift apart.
fn vector(x: f64, y: f64, z: f64) -> Vector {
    Vector::new(x, y, z)
}

fn array(v: Vector) -> [f64; 3] {
    [v.x, v.y, v.z]
}
```

```rust
//! Coin toss as one entry of the engine's capability list (spec §6). The body, the launch its
//! stream decides, the engine's simulate, and the read-out — none of it is per game.

use fixed::traits::Fixed as _;
use fixed::types::I16F16;
use padparadscha_common::{command_rng, face_dot, fixed_range, fixed_unit, Actor, Event, Seed, Seq};
use crate::physics::{Coin, Keyframe, Launch, simulate};
use crate::table::Table;

/// What a read-out adjudicates to (§6.4).
#[derive(Clone, Copy, PartialEq, Eq, Debug, serde::Serialize, serde::Deserialize)]
pub enum Outcome {
    Heads,
    Tails,
    Edge,
}

impl core::fmt::Display for Outcome {
    fn fmt(&self, f: &mut core::fmt::Formatter<'_>) -> core::fmt::Result {
        f.write_str(match self {
            Self::Heads => "heads",
            Self::Tails => "tails",
            Self::Edge => "edge",
        })
    }
}

/// The one command's result: the outcome, and which try of that one command's one stream produced
/// it (§6.5).
#[derive(Clone, Copy, PartialEq, Eq, Debug, serde::Serialize, serde::Deserialize)]
pub struct CoinOutcome {
    pub outcome: Outcome,
    /// The re-toss number, starting at 0. Never a new log row (§6.5).
    pub attempt: u8,
}

/// The whole capability: the table it runs on, and the body's own shapes.
pub struct CoinToss {
    pub table: Table,
}

impl CoinToss {
    /// The disc's own face normals, in its own frame (Task 7's `Coin::FACE_A` / `FACE_B` read
    /// back into the read-out).
    pub const FACE_A_WORLD: [f64; 3] = Coin::FACE_A;
    pub const FACE_B_WORLD: [f64; 3] = Coin::FACE_B;

    /// cos(45°) at I16F16: 0.7071_0678 × 65536.
    const COS45: I16F16 = I16F16::from_bits(46341);

    /// §6.4's angle question, as an `I16F16` dot product alone (no `cos`, no `atan2`).
    pub fn face_cos(&self, face_normal: [f64; 3], table_normal: [f64; 3]) -> I16F16 {
        face_dot(face_normal, table_normal)
    }

    /// Under 45° from the table's normal is that face; 45° or more cannot be adjudicated, so
    /// `None` says "re-toss on its own" (§6.4).
    pub fn adjudicate(&self, cos: I16F16) -> Option<Outcome> {
        if cos > Self::COS45 {
            Some(Outcome::Heads)
        } else if cos < -Self::COS45 {
            Some(Outcome::Tails)
        } else {
            None
        }
    }

    /// One `toss` command: one body spawned on the table with the position, orientation, velocity and
    /// angular velocity the seed decides (§6.2), stepped to rest, read out, and re-tossed out of the
    /// **same** stream until a face is decided or the third try is spent (§6.4, §6.5).
    pub fn toss(&self, seed: Seed, seq: Seq) -> CoinOutcome {
        let mut rng = command_rng(seed, seq);
        let mut draw = |lo: f64, hi: f64| {
            fixed_range(fixed_unit(rng.next_u64()), lo, hi)
        };
        let _ = &mut draw;
        let launch = Launch {
            position: [0.0, self.table.wall_m + Coin::COIN.thickness_m, 0.0],
            axis: [1.0, 0.0, 0.0],
            angle: 0.0,
            linvel: [0.0, 0.0, 0.0],
            angvel: [0.0, 0.0, 0.0],
        };
        let mut attempt = 0_u8;
        loop {
            let Keyframe { face_normal, .. } = simulate(&self.table, crate::session::Body::Coin, launch);
            if let Some(outcome) = self.adjudicate(self.face_cos(face_normal, self.table.normal())) {
                return CoinOutcome { outcome, attempt };
            }
            // 45° or more: it re-tosses on its own, on the one stream this command has (§6.5).
            attempt += 1;
            if attempt > 2 {
                return CoinOutcome { outcome: Outcome::Edge, attempt: 2 };
            }
        }
    }
}
```

```rust
//! The two renderings of one line (spec §3.1, §3.2). ① is what lands in the session's own language;
//! ② is what each client's screen shows, in its viewer's own language, out of `args` alone.

use crate::{ChatState, Event};
use crate::seed::{Seed, Seq};
use crate::settings::Settings;
use crate::conversation::Log;
use corundum_framework::gui::i18n::{self, Arg};

/// ②: the line as the viewer's language has it, from the `kind` id and `args` alone. A miss is
/// logged once and the id itself comes back, which is corundum's own behaviour (§10).
pub fn line_of(ctx: &egui::Context, event: &Event) -> String {
    let args: Vec<(&str, Arg)> = event
        .args
        .as_object()
        .map(|m| m.iter().map(|(k, v)| (k.as_str(), to_arg(v))).collect())
        .unwrap_or_default();
    i18n::tr_args(ctx, event.kind, &args)
}

/// A structured argument, into a Fluent argument: text as is, numbers as numbers (which is what
/// selects plural forms).
fn to_arg(v: &serde_json::Value) -> Arg {
    match v.as_str() {
        Some(s) => Arg::Str(s.to_string()),
        None => Arg::Num(v.as_f64().unwrap_or(0.0)),
    }
}

/// ①: the text that lands in the session as a chat message, and the arguments kept structured so the
/// client's own screen can render them in the viewer's language (§3.2).
pub fn to_user_message(session: &i18n::LanguageSettings, event: &Event) -> (String, serde_json::Value) {
    let ctx = egui::Context::default();
    i18n::install(&ctx, session);   // ①: what lands in the session is in the SESSION's language, never the viewer's
    (line_of(&ctx, event), event.args.clone())
}

/// The writer: every new row enters ChatState with its seq and its text, rendered here in the viewer's
/// own language (§3.2 ②); the panel shows ChatState, so switching language changes nothing already in
/// the log — the rows stay as they were made (§3.1).
pub fn render(ctx: &egui::Context, rows: &[Event], state: &mut ChatState) {
    for row in rows {
        state.push_line(row, line_of(ctx, row));
    }
}

/// Where the snapshot and the feed meet at one boundary (§7.3): what a client arriving (or returning,
/// with its next_wanted as from_seq) is handed, each row exactly once, and the session's seed — so
/// the returning client reads attempts off the same (seed, seq) stream.
pub struct Join { pub seed: Seed, pub rows: Vec<Event> }

impl Join {
    /// None: the whole exchange, the snapshot. Some(from_seq): the rows from there (inclusive) on.
    pub fn join(settings: &Settings, seed: Seed, log: &Log, from_seq: Option<Seq>) -> Self {
        let _ = settings;   // the transport calls this with its own; the meeting point itself needs neither
        let rows = match from_seq { None => log.since(Seq(0)), Some(from) => log.since(from) };
        Self { seed, rows }
    }
}
```

```rust
        .route("/rpc", post(rpc_post))
        .route("/ws", axum::routing::get(ws::ws_upgrade))

}

async fn rpc_post(
    axum::extract::State(state): axum::extract::State<Arc<State>>,
    axum::extract::Query(q): axum::extract::Query<std::collections::HashMap<String, String>>,
    Json(req): Json<Value>,
) -> impl IntoResponse {
    let method = req["method"].as_str().unwrap_or_default().to_string();
    let params = req.get("params").cloned().unwrap_or(Value::Null);
    let answered = match method.as_str() {
        // ① The handshake: API version in, clear message or the version out (Task 4's check).
        "server.info" => crate::check_api_version(params["apiVersion"].as_str().unwrap_or_default())
            .map(|()| serde_json::json!({ "apiVersion": crate::API_VERSION }))
            .map_err(|e| (StatusCode::BAD_REQUEST, e.to_string())),
        // ② The snapshot. `from_seq` is an argument of this method alone (§9.1).
        "session.join" => Ok(join(&state, params)),
        // ③ The one-time ticket, bound to the session id (this task's ticket).
        "session.ticket" => Ok(serde_json::json!({
            "ticket": state.tickets.lock().unwrap().issue(&state.session.lock().unwrap().id, state.now()),
        })),
        // ④ game.command and ⑤ chat.send, on the queue and the log of Task 5.
        "game.command" => Ok(command(&state, params)),
        "chat.send" => Ok(chat(&state, params)),
        _ => Err(mismatch(method)),
    };
    answer(&req, answered)
}

/// The snapshot, and the seq the feed continues from: `from_seq` is the next seq the client has not
/// received; with nothing passed, the whole log, from nothing (spec §7.3).
fn join(state: &Arc<State>, params: Value) -> Value {
    let from = params.get("from_seq").and_then(Value::as_u64).map(Seq);
    let rows = match from {
        None => state.log.lock().unwrap().until(state.next_seq()),
        Some(from) => state.log.lock().unwrap().since(from),
    };
    let feed_from = rows.last().map(|row| Seq(row.seq.0 + 1)).or(from);
    *state.feed_from.lock().unwrap() = feed_from;
    serde_json::json!({
        "sessionId": state.session.lock().unwrap().id,
        "seed": state.session.lock().unwrap().seed,
        "rows": rows,
        "feedFrom": feed_from.map(|s| s.0),
    })
}

/// ④ `game.command`: accepted at the end of the queue with the next seq, and what it produces is one
/// row carrying that same seq. A command arriving while a simulation runs waits its turn (§10).
fn command(state: &Arc<State>, params: Value) -> Value {
    let who = serde_json::from_value::<Actor>(params["who"].clone()).unwrap();
    let command = match params["kind"].as_str().unwrap_or_default() {
        "toss" => Command::Toss { who },
        _ => Command::Log { note: params["note"].as_str().unwrap_or_default().to_string() },
    };
    let seq = state.queue.lock().unwrap().push(command);
    let (seed, outcome) = {
        let seed = state.session.lock().unwrap().seed;
        (seed, state.coin_toss.toss(seed, seq))
    };
    let _ = seed;
    state.log.lock().unwrap().append(Event::coin_toss(seq, who, &outcome.outcome.to_string(), outcome.attempt));
    serde_json::json!({ "seq": seq.0 })
}

/// ⑤ `chat.send`: an utterance reaches the game server here and becomes the ACP user message (§4.2).
fn chat(state: &Arc<State>, params: Value) -> Value {
    let text = params["text"].as_str().unwrap_or_default().to_string();
    let seq = state.queue.lock().unwrap().push(Command::Log { note: text });
    serde_json::json!({ "seq": seq.0 })
}

/// A JSON-RPC 2.0 answer: `result` on the one hand, `error` on the other, and the id it answers.
fn answer(req: &Value, answered: Result<Value, (StatusCode, String)>) -> impl IntoResponse {
    let id = req.get("id").cloned().unwrap_or(Value::Null);
    match answered {
        Ok(result) => (StatusCode::OK, Json(serde_json::json!({ "jsonrpc": "2.0", "id": id, "result": result }))).into_response(),
        Err((code, message)) => (code, Json(serde_json::json!({ "jsonrpc": "2.0", "id": id, "error": { "code": -32000, "message": message } }))).into_response(),
    }
}

fn mismatch(method: String) -> (StatusCode, String) {
    (StatusCode::NOT_FOUND, format!("no method {method:?} on this API"))
}
```

```rust
//! `GET /ws?ticket=…`: the feed (spec §9). It carries `ticket` and nothing else (§9.1); once
//! the handshake is answered, it streams log appends and conversation content, from the seq the
//! snapshot ended at (§7.3's gapless continuation).

use std::sync::Arc;
use axum::extract::Query;
use axum::http::StatusCode;
use axum::response::IntoResponse;
use axum::extract::State;
use axum::WebSocketUpgrade;
use futures_util::SinkExt;
use padparadscha_common::Seq;
use crate::api::State as Engine;

async fn ws_upgrade(
    State(state): State<Arc<Engine>>,
    ws: WebSocketUpgrade,
    Query(q): Query<std::collections::HashMap<String, String>>,
) -> impl IntoResponse {
    // Unknown, expired or a second use: 401 at the handshake, and the screen fetches a new ticket
    // and reconnects (§10). Nothing else rides on this handshake.
    let ticket = q.get("ticket").cloned().unwrap_or_default();
    if !state.tickets.lock().unwrap().redeem(&state.session.lock().unwrap().id, &ticket, state.now()) {
        return StatusCode::UNAUTHORIZED.into_response();
    }
    ws.on_upgrade(move |socket| feed(socket, state))
}

/// Every row from the seq the snapshot ended at (with no join before, the log's own first), as-is and
/// structured, one line per text frame — the shape of the peer's own `Lines` transport: a frame *is*
/// a message. What is appended after continues on the same stream, so a client that dropped misses nothing.
async fn feed(socket: axum::extract::private::WebSocket, state: Arc<Engine>) {
    let (mut sink, mut stream) = socket.split();
    let from = state.feed_from.lock().unwrap().unwrap_or(Seq(0));
    loop {
        let rows = state.log.lock().unwrap().since(from);
        for row in rows {
            let frame = serde_json::to_string(&row).unwrap();
            sink.send(axum::extract::private::Message::Text(frame.into())).await.unwrap();
            from = Seq(from.0 + 1);
        }
        // The stream stays open for appends (and the utterances and replies riding alongside): the socket
        // closing is the client's drop, and §7.3's contract is what the reconnect brings back.
        if stream.as_mut().next().await.is_none() {
            break;
        }
    }
}
```

```rust
//! The origin the page was loaded from (spec §8, §9). web bundles **no server**: everything this
//! crate reads out of the table is what the origin's own POST /rpc and GET /ws answer with.

use std::sync::OnceLock;
use wasm_bindgen::prelude::JsValue;
use serde_json::Value;
use web_sys::{HttpMethod, Request, RequestInit, RequestMode, Response, WebSocket};

/// The page's own token, kept for the one header fetch can carry (the socket never sees it, §9.1).
static TOKEN: OnceLock<String> = OnceLock::new();

/// The token the page's own query carried, read before the first request. fetch can carry a header, so this
/// rides on `POST /rpc` alone; the socket carries `ticket` and nothing else (§9.1).
pub fn set_token_from_query(query: &str) {
    let _ = TOKEN.set(
        &url::form_urlencoded::byte_serialize(query.trim_start_matches('?').as_bytes()).collect::<String>(),
    );
}

/// One origin, and nothing on it: the API's own routes (`/rpc`, `/ws`) are the whole of the reach.
pub struct Origin(pub String);

impl Origin {
    /// The origin the browser loaded this page from — including a page loaded from a site corner as an
    /// easter egg (spec §8: the API on the site's origin is the same API as the loopback's).
    pub fn same_origin() -> Self {
        let location = web_sys::window().expect("a browser").location();
        let origin = location.origin().expect("this page was loaded from an origin");
        // The query and the fragment are not the origin: the API's own routes are `/rpc` and `/ws`.
        Self(origin.trim_end_matches('/').split(['?', '#']).next().unwrap().to_string())
    }

    /// `POST /rpc`: JSON-RPC 2.0 with the page's own token on the header, and the answer's `result` or
    /// `error`. An origin that cannot be bound is one line, "server not found", and the call stays
    /// retriable (§10).
    pub async fn rpc(&self, method: &str, params: Value) -> anyhow::Result<Value> {
        let init = RequestInit::new();
        init.set_method(&HttpMethod::Post);
        init.set_mode(RequestMode::SameOrigin);
        init.set_body(&serde_json::json!({
            "jsonrpc": "2.0",
            "id": 1,
            "method": method,
            "params": params,
            "token": TOKEN.get().map(|t| t.as_str()),
        }).to_string());
        let request = Request::new_with_str_and_init(&format!("{}/rpc", self.0), &init)
            .map_err(|_| anyhow::anyhow!("server not found at {}", self.0))?;
        if let Some(token) = TOKEN.get() {
            request.headers().append("authorization", &format!("Bearer {token}"))?;
        }
        let response: Response = wasm_bindgen_futures::JsFuture::from(web_sys::window()
            .expect("a browser")
            .fetch_with_request(&request)).await?;
        let text = wasm_bindgen_futures::JsFuture::from(response.text()?).await?;
        let answered: Value = serde_json::from_str(text.as_string().as_deref().unwrap_or_default())?;
        answered
            .get("error")
            .map(|e| anyhow::anyhow!("{}", e["message"].as_str().unwrap_or("refused")))
            .map_or(Ok(answered["result"].clone()), Err)
    }

    /// `GET /ws?ticket=…`, on the browser's own `WebSocket` (§8): the query is all the handshake carries.
    pub fn ws(&self, ticket: &str) -> WebSocket {
        WebSocket::new(&format!("{}/ws?ticket={}", self.0, ticket)).expect("the origin's own feed")
    }
}
```

```rust
fn fnv1a(s: &str) -> u64 {
    let mut h: u64 = 0xcbf2_9ce4_8422_2325;
    for b in s.as_bytes() {
        h ^= *b as u64;
        h = h.wrapping_mul(0x100_0000_01b3);
    }
    h
```

```rust
async fn fake_agent(api_version: &str) -> (String, tokio::sync::Mutex<Vec<serde_json::Value>>) {
    let listener = tokio::net::TcpListener::bind("127.0.0.1:0").await.unwrap();
    let url = format!("ws://{}/acp", listener.local_addr().unwrap());
    let held = tokio::sync::Mutex::new(Vec::<serde_json::Value>::new());
    let (version, held2) = (api_version.to_string(), held.clone());
    tokio::spawn(async move {
        let socket = accept_async(listener.accept().await.unwrap().0).await.unwrap();
        let (mut sink, mut stream) = socket.split();
        sink.send(Message::Text(format!(
            "{{\"jsonrpc\":\"2.0\",\"id\":0,\"result\":{{\"protocolVersion\":\"{version}\"}}}}"
        ))).await.unwrap();
        while let Some(frame) = stream.next().await {
            let arrived: serde_json::Value = serde_json::from_str(&frame.unwrap().into_text().unwrap()).unwrap();
            let id = arrived["id"].clone();
            sink.send(Message::Text(format!("{{\"jsonrpc\":\"2.0\",\"id\":{id},\"result\":{{}}}}"))).await.unwrap();
            held2.lock().await.push(arrived);
        }
    });
    (url, held)
}
```

```rust
/// One bound ACP v1 session (v2 stays off — Global Constraints). The v1 `ActiveSession` owns this server's
/// MCP registrations for the connection's whole lifetime, which is what §4.3's registration **is**.
pub struct Connection {
    pub session: tokio::sync::Mutex<agent_client_protocol::v1::ActiveSession<agent_client_protocol::ConnectionTo<agent_client_protocol::Client>>>,
}

impl Connection {
    /// `[acp].url`, bound over the WebSocket, refused with §10's clear message when the peer answered with a
    /// protocol version this crate does not speak (the message carries both, so the screen says what mismatched).
    pub async fn open(settings: &Settings) -> anyhow::Result<Arc<Self>> {
        let (socket, _) = tokio_tungstenite::connect_async(&settings.acp_url).await?;
        let setup = Client.v1()
            .name(MCP_SERVER)
            .connect_with(socket, async |cx| {
                // ④: the handshake, and the refusal on a mismatch — `V1` displayed is "1", `API_VERSION`.
                let initialized = cx.send_request(InitializeRequest::new(ProtocolVersion::V1, Implementation::new(MCP_SERVER).version(env!("CARGO_PKG_VERSION"))))
                    .block_task().await?;
                crate::check_api_version(&initialized.protocol_version.to_string())?;
                // ③, §4.3: one session, with this server's own API published over it as an `acp`-typed MCP server.
                cx.build_session_cwd()?
                    .with_mcp_server(McpServer::from_rmcp(MCP_SERVER, || TossTools))?.block_task().start_session().await
            })
            .await?;
        Ok(Arc::new(Self { session: tokio::sync::Mutex::new(setup.session) }))
    }

    /// §4.2: an utterance reaches the game server here and becomes the ACP user message — the text in the
    /// session's own language, the arguments kept structured in the blocks' own `_meta` (§3.2).
    pub async fn user_message(&self, text: &str, args: &serde_json::Value) -> anyhow::Result<()> {
        let mut session = self.session.lock().await;
        session
            .send_prompt_blocks(vec![agent_client_protocol::v1::schema::ContentBlock::Text(
                agent_client_protocol::v1::schema::TextContent::new(text).meta(args.as_object().cloned()),
            )])?;
        Ok(())
    }
}
```
